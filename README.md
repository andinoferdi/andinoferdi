## A Little About Me

I started programming while studying Software Engineering at SMKN 2 Surabaya. I am now continuing that journey as an Informatics student at Universitas Airlangga.

I enjoy turning ideas into working products, especially web applications with clear workflows, practical features, and intuitive interfaces.

My current focus is backend development with Laravel, modern frontend development with Vue and React, and cross-platform mobile development with Flutter.

Outside programming, I enjoy listening to rock music from the 60s through the 90s.
